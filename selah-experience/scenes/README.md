# Scene placeholders

Stillness, Horizon and Resonance are static SVG compositions using Selah tokens.
They are deliberately placeholders, not final wallpapers or replacement branding.
No text or new logo is embedded. No animation, texture downloads or video.

Installed under `/usr/share/selah-experience/scenes/` for manual preview, not
selected as default wallpapers. Existing cosmic wallpapers remain untouched.
